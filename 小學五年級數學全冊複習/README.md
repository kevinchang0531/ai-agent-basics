# 國小五年級數學全冊複習

這是一份依 `math-review-deck` 風格製作的純前端互動複習簡報，涵蓋五上、五下常見的 20 個單元。

## 使用方式

直接以瀏覽器開啟 `index.html` 即可。若瀏覽器限制 `file://` 的 JavaScript，請在此資料夾執行：

```bash
python -m http.server 8890
```

再開啟 <http://localhost:8890>。

## 範圍說明

各出版社的單元名稱與順序可能略有差異。本版採用 108 課綱下常見的五上、五下章節架構，適合作為跨版本複習底稿；若提供實際課本版本或考試範圍，可再精準調整。
